## How Lilac Works

<Steps>
  <Step title="Tell Lilac the goal">
    Start with a plain-language description of what you want done. Add a connected project — like a GitHub repository or Notion workspace — when the task needs one, and Lilac picks up the context automatically.
  </Step>
  <Step title="Watch it work">
    Lilac runs in its own cloud environment, so you don't need to stay on the page. Return to your workspace thread at any time to follow its progress, see which tools it used, and track each step as it happens.
  </Step>
  <Step title="Review the result">
    When Lilac finishes, check the output directly in the thread. For GitHub projects, it opens a pull request for your review before anything is merged — you stay in control of what ships.
  </Step>
</Steps>
