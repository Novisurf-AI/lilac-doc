Lilac is an AI agent workspace that takes your plain-language descriptions and turns them into finished work. You tell it what you need, and it plans, executes, and delivers — autonomously, in its own cloud environment — while you stay in the loop through a live workspace thread. Whether you're fixing a bug, building a page, or tracking a deadline, Lilac works through the task and brings the result back for you to review.

## What Lilac Can Do

Lilac is built around a core idea: context, a computer, and timely reminders in one place. Here's what that means in practice:

- **Build and ship code** — Lilac can build websites, explore codebases, fix bugs, and open pull requests for your review before anything gets merged.
- **Use its own cloud computer** — It browses the web, spins up environments, and checks its own results in a dedicated cloud workspace — no setup required on your end.
- **Connect to your existing tools** — Bring GitHub, Notion, Gmail, and Calendar into Lilac so it has the context each task needs.
- **Remember and remind** — Tell Lilac about a calendar event and it keeps the details in mind, notifying you when the moment is approaching.
- **Show live progress** — Every step, tool call, and decision appears in the workspace thread in real time, so you always know what Lilac is doing.

## How It Works

Lilac follows a straightforward loop: you set the goal, it does the work, and you review what it made.

<Steps>
  <Step title="Tell Lilac the goal">
    Start with a plain-language description of what you need. Add a connected project — like a GitHub repository or a Notion workspace — when the task requires one. No special syntax or prompting knowledge needed.
  </Step>
  <Step title="Watch it work">
    Lilac gets to work immediately. The workspace thread shows each step it takes, the tools it uses, and its progress in real time. You don't need to stay on the page — runs continue on Lilac's worker in the background.
  </Step>
  <Step title="Review the result">
    When the task is complete, the output appears in the thread. Check the result, ask for changes, or — for GitHub-connected projects — open the pull request and merge when you're satisfied.
  </Step>
</Steps>

## Frequently Asked Questions

<Accordion title="What can I ask Lilac to do?">
  You can ask Lilac to build a website, explore a codebase, fix a bug, or make a change in a connected repository. It works in its own cloud environment and brings the result back for you to review. As Lilac is in early beta, its capabilities are actively expanding.
</Accordion>

<Accordion title="Can Lilac use my existing tools?">
  Yes. You can connect supported tools directly from the workspace. GitHub and Notion are available through their own connection flows, and you choose exactly what you authorize. Once connected, Lilac can use those tools as part of any task that needs them.
</Accordion>

<Accordion title="Do I need to leave the page open?">
  No. Runs continue on Lilac's worker even after you close the tab or step away. Return to the workspace at any time to see the progress, review the work, and continue the conversation where you left off.
</Accordion>

<Accordion title="How do I review the result?">
  Lilac shows every step and all output in the thread so you have a full picture of what it did. For tasks connected to a GitHub project, it opens a pull request for you to review the changes before anything gets merged into your codebase.
</Accordion>
