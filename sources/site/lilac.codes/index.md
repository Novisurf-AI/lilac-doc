## Frequently asked questions

What can I ask Lilac to do?

Ask Lilac to build a website, explore a codebase, fix a bug, or make a change in a connected repository. It can work in its own cloud environment and bring the result back for review.

Can Lilac use my existing tools?

You can connect supported tools from the workspace. GitHub projects and Notion are available through their connection flows; you choose what to authorize.

Do I need to leave this page open?

No. Runs continue on Lilac’s worker. Return to the workspace to see the progress, review the work, and continue the conversation.

How do I review the result?

Lilac shows the steps and output in the thread. For a connected GitHub project, you can review the changes and pull request before merging.
